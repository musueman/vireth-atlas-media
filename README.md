# Vireth atlas map images

Public settlement-map WebP display derivatives used by [Vireth Atlas](https://musueman.github.io/vireth-atlas-site/). Original PNGs are preserved in the production source. Full-size display WebP is high-quality lossy Q94/method6 at original dimensions, encoded directly from production PNGs with alpha and ICC preserved. Older lossless files remain available; small previews are separate. Filenames are SHA-256 hashes; existing images stay available for previously published snapshots. No lore source archives or private production material are included.
