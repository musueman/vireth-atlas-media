# Vireth atlas map images

Public settlement-map WebP display derivatives used by [Vireth Atlas](https://musueman.github.io/vireth-atlas-site/). Original PNGs are preserved in the production source. Full-size WebP pixels are verified identical; small previews are separate. Filenames are SHA-256 hashes; existing images stay available for previously published snapshots. No lore source archives or private production material are included.
